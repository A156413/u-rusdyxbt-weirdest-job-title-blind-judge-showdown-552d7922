Entry for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty ($5 in USDC).

The entry is a single job title, 60 characters at most and nothing else: **Senior Penguin Relocation Coordinator** — it sounds like a real corporate/conservation job, a senior coordinator role, with one hilariously specific twist: the thing being relocated is penguins. A deadpan judge reads it as a plausible job with a gloriously odd assignment, which lands on the first read instead of reading as random word salad.

`main.py` writes that title to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints the same line to stdout. Deterministic: no network, no randomness, no clock.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
